# Exercises

每日 Python 进阶练习放这里，按日期建目录，例如：

```
exercises/
└── 2026-09-08_type_hints/
    ├── exercise.py        # 练习代码
    └── summary.md         # 2-3 行总结：今天学会了什么
```

练习主题参考（来自学习计划 2026.09–2026.10）：
- 类型注解（Type Hints）与 `typing` 常用类型
- 异步编程 `async / await` 与并发模型
- pydantic 数据校验
- 用 unittest / pytest 写测试
- 其他按需补充

铁律：练习代码必须当天跑通 + 当天 commit，不做"看完就忘"的假学习。
