### ❌ 第2题：append vs extend

**原题：**
```python
fruits = ['apple', 'banana']
fruits.append(['orange', 'grape'])
```
问 `fruits` 的值是什么？

**正确答案：** B. `['apple', 'banana', ['orange', 'grape']]`

**解析：**
- `append(x)` 把 x 作为**一个整体**添加到末尾
- 如果 x 是列表，则列表本身成为一个嵌套元素
- 要想把列表中的元素逐个添加，应该用 `extend()`

```python
# append：整体添加
a = [1, 2]
a.append([3, 4])
print(a)  # [1, 2, [3, 4]]

# extend：逐个添加
b = [1, 2]
b.extend([3, 4])
print(b)  # [1, 2, 3, 4]
```

### ❌ 第4题：sort() 返回值

**原题：** 关于 `list.sort()` 方法，以下说法正确的是？

**正确答案：** D. B 和 C 都正确（原地排序返回 None + 可指定 reverse=True）

**解析：**
- Python 中**原地修改**可变对象的方法都返回 `None`
- 这是设计原则：修改操作不返回值，避免链式调用的误解

```python
nums = [3, 1, 4, 1, 5]

# sort() 原地排序，返回 None
result = nums.sort()
print(result)  # None
print(nums)    # [1, 1, 3, 4, 5]

# 想要新列表，用 sorted()
nums2 = [3, 1, 4, 1, 5]
new_nums = sorted(nums2)
print(new_nums)  # [1, 1, 3, 4, 5]
print(nums2)     # [3, 1, 4, 1, 5]（原列表不变）
```

**同类方法：** `reverse()`、`clear()`、`insert()`、`remove()` 都返回 `None`

### ❌ 第12题：dict.get()

**原题：**
```python
d = {'a': 1, 'b': 2}
print(d.get('c', 0))
```

**正确答案：** B. `0`

**解析：**
- `d[key]` → 键不存在时抛出 `KeyError`
- `d.get(key)` → 键不存在时返回 `None`
- `d.get(key, default)` → 键不存在时返回 `default`

```python
d = {'a': 1, 'b': 2}

# 方式1：直接取值（不安全）
d['c']        # ❌ KeyError: 'c'

# 方式2：get() 安全取值
d.get('c')          # None
d.get('c', 0)       # 0（指定默认值）
d.get('c', 'N/A')   # 'N/A'

# 方式3：setdefault()（取值+不存在时设置）
d.get('c', 0)       # 0（不修改字典）
d.setdefault('c', 0)  # 0（同时 d['c'] = 0）
```

### ❌ 第15题：zip() 函数

**原题：** `zip([1, 2], ['a', 'b'])` 的结果是？

**正确答案：** A. `[(1, 'a'), (2, 'b')]`

**解析：**
- `zip()` 将多个序列的对应元素**打包成元组**
- 返回的是 zip 对象（迭代器），转列表后是元组列表
- 长度以最短的序列为准

```python
# 基本用法
list(zip([1, 2, 3], ['a', 'b', 'c']))
# [(1, 'a'), (2, 'b'), (3, 'c')]

# 长度不同，以短的为准
list(zip([1, 2, 3, 4], ['a', 'b']))
# [(1, 'a'), (2, 'b')]

# 三个序列
list(zip([1, 2], ['a', 'b'], [True, False]))
# [(1, 'a', True), (2, 'b', False)]

# 常见用法：并行遍历
names = ['Alice', 'Bob']
scores = [85, 92]
for name, score in zip(names, scores):
    print(f"{name}: {score}")

# 常见用法：创建字典
dict(zip(['a', 'b', 'c'], [1, 2, 3]))
# {'a': 1, 'b': 2, 'c': 3}
```

### ❌ 第30题：元组解包

**原题：** 元组打包：`t = 1, 2, 3`，解包：`a, b, c = ______`

**正确答案：** `t`

**解析：**
```python
# 打包：多个值 → 一个元组
t = 1, 2, 3        # t = (1, 2, 3)
t = (1, 2, 3)      # 等价写法

# 解包：一个元组 → 多个变量
a, b, c = t        # a=1, b=2, c=3

# 解包适用于任何序列
x, y, z = [10, 20, 30]    # 列表
x, y, z = 'abc'            # 字符串
x, y, z = range(3)         # range对象

# 数量必须匹配
a, b = (1, 2, 3)    # ❌ ValueError: too many values
a, b, c, d = (1, 2)  # ❌ ValueError: not enough values

# 星号解包：收集多余元素
first, *rest = (1, 2, 3, 4, 5)
# first = 1, rest = [2, 3, 4, 5]

first, *middle, last = (1, 2, 3, 4, 5)
# first = 1, middle = [2, 3, 4], last = 5
```

### ❌ 第52题：set + sorted 去重排序

**原题回顾：**
```python
nums = [3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5]
# 去重 + 升序排序
```

**正确写法：**
```python
nums = [3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5]

# 一步到位
result = sorted(set(nums))
print(result)  # [1, 2, 3, 4, 5, 6, 9]
```

**拆解理解：**
```python
# 第1步：set() 去重
set(nums)  # {1, 2, 3, 4, 5, 6, 9}

# 第2步：sorted() 排序（返回新列表）
sorted(set(nums))  # [1, 2, 3, 4, 5, 6, 9]

# 注意：sorted() 返回 list，set() 返回 set
# sorted(set(nums)) 的结果类型是 list
```

### ❌ 第54题：词频统计

**原题回顾：**
```python
text = "hello world hello python world hello"
# 统计每个单词出现次数
```

**正确写法：**
```python
text = "hello world hello python world hello"
words = text.split()

# 方法1：普通循环
freq = {}
for word in words:
    if word in freq:
        freq[word] += 1
    else:
        freq[word] = 1

# 方法2：get() 简化
freq = {}
for word in words:
    freq[word] = freq.get(word, 0) + 1

# 方法3：推导式（不推荐，效率低）
freq = {w: words.count(w) for w in set(words)}

# 方法4：collections.Counter（最推荐）
from collections import Counter
freq = Counter(words)

print(freq)
# {'hello': 3, 'world': 2, 'python': 1}
```

### ❌ 第55题：字典综合应用

**原题回顾：**
```python
scores = {'Alice': 85, 'Bob': 92, 'Charlie': 78, 'David': 95}
# 1. 最高分学生  2. 90分以上  3. 平均分  4. 排序输出
```

**正确写法：**
```python
scores = {'Alice': 85, 'Bob': 92, 'Charlie': 78, 'David': 95}

# 1. 最高分学生
top_student = max(scores, key=scores.get)
top_score = scores[top_student]
print(f"最高分: {top_student} - {top_score}")  # David - 95

# 2. 90分以上
high_scores = [name for name, score in scores.items() if score >= 90]
print(f"90分以上: {high_scores}")  # ['Bob', 'David']

# 3. 平均分
avg = sum(scores.values()) / len(scores)
print(f"平均分: {avg:.1f}")  # 87.5

# 4. 按成绩排序输出
sorted_scores = sorted(scores.items(), key=lambda x: x[1], reverse=True)
for name, score in sorted_scores:
    print(f"{name}: {score}")
# David: 95 / Bob: 92 / Alice: 85 / Charlie: 78
```

**关键函数解析：**
```python
# max(dict, key=dict.get) → 找值最大的键
max(scores, key=scores.get)  # 'David'

# sorted(dict.items(), key=lambda x: x[1]) → 按值排序
# x[0] 是键，x[1] 是值
sorted(scores.items(), key=lambda x: x[1], reverse=True)
```

**10.1**
```python
text = "the quick brown fox jumps over the lazy dog the fox"
words = text.split()

# 1. 统计词频
freq = {}
for w in words:
    freq[w] = freq.get(w, 0) + 1

# 2. 出现最多的单词
most_common = max(freq, key=freq.get)
print(f"出现最多: {most_common} ({freq[most_common]}次)")

# 3. 前3名
top3 = sorted(freq.items(), key=lambda x: x[1], reverse=True)[:3]
for word, count in top3:
    print(f"{word}: {count}")
```
