# Python 错误和异常 — 学习笔记

> 来源：[Python 官方文档 - 第8章 错误和异常](https://docs.python.org/zh-cn/3/tutorial/errors.html)

---

## 一句话理解

**语法错误** = 代码写错了（Python 看不懂）  
**异常** = 代码写对了但运行出错（Python 执行不下去）

---

## 1. 语法错误（SyntaxError）

就是代码写错了，Python 解析不了。

```python
# 少了冒号
while True print("Hello")
# SyntaxError: invalid syntax

# 正确写法
while True:
    print("Hello")
```

**特点：** 运行前就能发现，箭头指向出错位置。

---

## 2. 异常（Exception）

代码语法没问题，但运行时报错。

```python
# 除以零
10 * (1/0)
# ZeroDivisionError: division by zero

# 变量没定义
4 + spam * 3
# NameError: name 'spam' is not defined

# 类型不对
'2' + 2
# TypeError: can only concatenate str (not "int") to str
```

### 常见异常速查

| 异常 | 触发场景 |
|------|---------|
| `ZeroDivisionError` | 除以零 |
| `NameError` | 变量未定义 |
| `TypeError` | 类型不对 |
| `ValueError` | 值不对（如 `int("abc")`） |
| `IndexError` | 索引越界 |
| `KeyError` | 字典键不存在 |
| `FileNotFoundError` | 文件不存在 |
| `AttributeError` | 属性/方法不存在 |
| `ImportError` | 导入失败 |
| `KeyboardInterrupt` | 用户按 Ctrl+C |

## 3. 异常处理（try/except）

### 基本结构

```python
try:
    # 可能出错的代码
    x = int(input("请输入数字："))
except ValueError:
    # 出错时执行
    print("输入的不是数字！")
```

### 完整结构（四个子句）

```python
try:
    # 1. 可能出错的代码
    result = 10 / 2
except ZeroDivisionError:
    # 2. 出错时执行
    print("除以零了！")
else:
    # 3. 没出错时执行
    print(f"结果是 {result}")
finally:
    # 4. 无论如何都执行
    print("清理工作")
```

**执行流程：**
```
try → 没出错 → else → finally
try → 出错 → except → finally
```

### 捕获多种异常

```python
try:
    result = 10 / 0
except ZeroDivisionError:
    print("除以零了")
except TypeError:
    print("类型错误")
except (ValueError, RuntimeError):  # 多个异常放一起
    print("值错误或运行时错误")
except Exception as e:  # 兜底（捕获所有）
    print(f"其他错误：{e}")
```

### 获取异常信息

```python
try:
    x = int("abc")
except ValueError as e:
    print(f"错误类型：{type(e)}")  # <class 'ValueError'>
    print(f"错误信息：{e}")        # invalid literal for int()...
```

### ⚠️ 最佳实践

```python
# ❌ 不推荐：捕获所有异常
try:
    do_something()
except Exception:
    pass  # 吞掉了所有错误，调试困难

# ✅ 推荐：只捕获你知道如何处理的
try:
    value = int(data)
except ValueError:
    value = 0  # 知道怎么处理
```

## 4. 触发异常（raise）

主动抛出异常。

```python
# 方式1：直接抛
raise ValueError("值不对")

# 方式2：先创建再抛
error = ValueError("值不对")
raise error

# 方式3：重新抛出当前异常
try:
    1/0
except ZeroDivisionError:
    print("记录一下错误")
    raise  # 继续往上抛
```

---

## 5. 异常链（from）

一个异常导致另一个异常时，用 `from` 链接。

```python
try:
    open("不存在的文件.txt")
except FileNotFoundError as e:
    raise RuntimeError("打开数据库失败") from e

# 输出会显示两个异常的因果关系
```

**隐藏原始异常：**
```python
raise RuntimeError("新错误") from None  # 不显示原始异常
```

## 6. 自定义异常

继承 `Exception` 类。

```python
class MyError(Exception):
    """自定义异常"""
    pass

class ValidationError(Exception):
    """数据验证错误"""
    def __init__(self, field, message):
        self.field = field
        self.message = message
        super().__init__(f"{field}: {message}")

# 使用
def validate_age(age):
    if age < 0:
        raise ValidationError("age", "年龄不能为负数")

try:
    validate_age(-1)
except ValidationError as e:
    print(f"字段 {e.field} 验证失败：{e.message}")
```

**命名规范：** 异常类名以 `Error` 结尾。

## 7. finally 清理操作

**无论是否出错，finally 都会执行。**

```python
try:
    f = open("data.txt")
    data = f.read()
finally:
    f.close()  # 保证文件被关闭
```

### 典型用法

```python
# 关闭文件
try:
    f = open("file.txt")
    f.read()
finally:
    f.close()

# 关闭数据库连接
try:
    conn = connect_db()
    conn.query("SELECT ...")
finally:
    conn.close()

# 释放锁
try:
    lock.acquire()
    do_something()
finally:
    lock.release()
```

### ⚠️ 注意

```python
def test():
    try:
        return True
    finally:
        return False  # finally 的 return 会覆盖 try 的！

print(test())  # False
```

## 8. with 语句（推荐）

`with` 自动处理清理操作，比 `try/finally` 更简洁。

```python
# ❌ 传统写法
f = open("file.txt")
try:
    data = f.read()
finally:
    f.close()

# ✅ with 写法（自动关闭）
with open("file.txt") as f:
    data = f.read()
```

**with 的好处：**
- 代码更短
- 自动关闭（即使出错）
- 不用写 finally

## 9. ExceptionGroup（Python 3.11+）

同时抛出多个不相关的异常。

```python
def run_tasks():
    errors = []
    
    # 模拟多个任务失败
    try:
        raise OSError("磁盘错误")
    except OSError as e:
        errors.append(e)
    
    try:
        raise ValueError("数据错误")
    except ValueError as e:
        errors.append(e)
    
    # 打包抛出
    if errors:
        raise ExceptionGroup("多个任务失败", errors)

# 捕获
try:
    run_tasks()
except* OSError as e:
    print("处理磁盘错误")
except* ValueError as e:
    print("处理数据错误")
```

## 10. add_note（Python 3.11+）

给异常添加额外信息。

```python
try:
    raise TypeError("类型错误")
except Exception as e:
    e.add_note("发生在用户登录时")
    e.add_note(f"用户ID: 12345")
    raise

# 输出：
# TypeError: 类型错误
# 发生在用户登录时
# 用户ID: 12345
```

## 速查表

```
异常处理结构:
  try:           → 可能出错的代码
  except:        → 出错时执行
  else:          → 没出错时执行
  finally:       → 无论如何都执行

常用写法:
  try/except              → 基本错误处理
  try/except/else         → 区分成功/失败
  try/except/finally      → 出错+清理
  try/except/else/finally → 完整结构
  with                    → 自动清理（推荐）

触发异常:
  raise ValueError("msg")     → 抛出新异常
  raise                       → 重新抛出当前异常
  raise X from Y              → 异常链
  raise X from None           → 隐藏原始异常

自定义异常:
  class MyError(Exception):   → 继承 Exception
      pass

最佳实践:
  ✓ 只捕获你知道如何处理的异常
  ✓ 用 with 管理资源
  ✓ 异常类名以 Error 结尾
  ✗ 不要用 except: pass 吞掉错误
  ✗ 不要在 finally 里 return
```

## 常见场景模板

### 1. 输入验证

```python
while True:
    try:
        age = int(input("请输入年龄："))
        if age < 0:
            raise ValueError("年龄不能为负")
        break
    except ValueError as e:
        print(f"输入错误：{e}")
```

### 2. 文件操作

```python
try:
    with open("data.txt", "r", encoding="utf-8") as f:
        data = f.read()
except FileNotFoundError:
    print("文件不存在")
except PermissionError:
    print("没有权限读取")
```

### 3. 网络请求

```python
import requests

try:
    response = requests.get("https://api.example.com/data")
    response.raise_for_status()  # 状态码不是200会抛异常
    data = response.json()
except requests.exceptions.RequestException as e:
    print(f"请求失败：{e}")
```

### 4. 函数错误处理

```python
def divide(a, b):
    try:
        return a / b
    except ZeroDivisionError:
        return None  # 或者返回默认值
    except TypeError:
        raise ValueError("参数必须是数字") from None
```
