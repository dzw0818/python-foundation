### ❌ 第5题：with 自动关闭文件

**原题：** 哪种写法能自动关闭文件？

**正确答案：** B. `with open("test.txt") as f: f.read()`

**解析：**
```python
# ❌ 手动关闭，容易忘记
f = open("test.txt")
content = f.read()
f.close()  # 忘了写就泄漏了

# ✅ with 自动关闭（推荐）
with open("test.txt") as f:
    content = f.read()
# 离开 with 块，自动关闭，即使中间报错

# ❌ 这种写法文件不会及时关闭
content = open("test.txt").read()  # 不推荐
```

**记忆口诀：** 打开文件用 with，自动关闭不担心。

### ❌ 第8题：import * 为什么不推荐

**原题：** 关于 `from module import *`，说法正确的是？

**正确答案：** C. 可能覆盖已有同名变量，不推荐

**解析：**
```python
# 假设 math.py 里有个变量叫 max
from math import *

# 你的代码里本来用内置的 max()
max([1, 2, 3])  # 突然变成了 math.max，逻辑出错！

# 推荐做法：明确导入
from math import sqrt, pi
# 或者
import math
math.sqrt(16)
```

**记忆口诀：** import * 一时爽，命名冲突火葬场。

### ❌ 第9题：文件读取方法区别

**原题：** 读取文件所有行并返回列表，应使用？

**正确答案：** C. `f.readlines()`

**解析：**
```python
with open("test.txt") as f:
    # read() → 返回整个文件内容（一个字符串）
    content = f.read()
    # "hello\nworld\npython"
    
    # readline() → 返回一行（字符串）
    line = f.readline()
    # "hello\n"
    
    # readlines() → 返回所有行（列表）
    lines = f.readlines()
    # ["hello\n", "world\n", "python\n"]
    
    # 逐行遍历 → 省内存（大文件推荐）
    for line in f:
        print(line.strip())
```

**速记表：**
| 方法 | 返回类型 | 内容 |
|------|---------|------|
| `read()` | 字符串 | 整个文件 |
| `readline()` | 字符串 | 一行 |
| `readlines()` | 列表 | 所有行 |
| `for line in f` | 迭代器 | 逐行 |

### ❌ 第14题：二进制模式

**原题：** 读取二进制文件（如图片），mode 应设为？

**正确答案：** `"rb"`

**解析：**
```python
# 文本文件（.txt, .csv, .json）
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()  # 返回字符串

# 二进制文件（图片、视频、音频）
with open("photo.jpg", "rb") as f:  # 注意是 rb
    data = f.read()  # 返回 bytes

# 模式速查
# "r"  → 文本读
# "w"  → 文本写（覆盖）
# "a"  → 文本追加
# "rb" → 二进制读
# "wb" → 二进制写
# "ab" → 二进制追加
```

**记忆口诀：** 文本加 encoding，二进制加 b。

### ❌ 第30题：f-string 表格对齐

**原题：** 用 f-string 输出整齐的表格

**正确写法：**
```python
products = [
    ("笔记本电脑", 5999.5),
    ("鼠标", 129.0),
    ("键盘", 299.9),
]

# 对齐方式：
# < 左对齐
# > 右对齐  
# ^ 居中

print(f"{'商品名称':<10}{'价格':>10}")
print("-" * 20)
for name, price in products:
    print(f"{name:<10}{price:>10.2f}")

# 输出：
# 商品名称          价格
# --------------------
# 笔记本电脑       5999.50
# 鼠标              129.00
# 键盘              299.90
```

**对齐语法：**
```python
f"{value:<10}"   # 左对齐，宽度10
f"{value:>10}"   # 右对齐，宽度10
f"{value:^10}"   # 居中，宽度10
f"{value:0>5}"   # 右对齐，补零到5位
f"{value:.2f}"   # 保留2位小数
f"{value:>10.2f}" # 右对齐+2位小数
```

### ❌ 第31题：文件追加写入

**原题：** 创建文件写入内容，再追加内容

**正确写法：**
```python
# 第一次：用 "w" 创建并写入
with open("diary.txt", "w", encoding="utf-8") as f:
    f.write("2026-09-11 开始学Python\n")

# 第二次：用 "a" 追加（不会覆盖原内容）
with open("diary.txt", "a", encoding="utf-8") as f:
    f.write("今天学会了文件读写！\n")

# 如果用 "w" 会怎样？
with open("diary.txt", "w", encoding="utf-8") as f:  # ❌ 原内容被清空！
    f.write("新内容\n")

# 读取验证
with open("diary.txt", "r", encoding="utf-8") as f:
    print(f.read())
```

**记忆口诀：** w 写新（覆盖），a 追加（保留）。

### ❌ 第32题：JSON 读写

**原题：** 保存联系人数据到 JSON 文件

**正确写法：**
```python
import json

contacts = {
    "Alice": {"phone": "13800001111"},
    "Bob": {"phone": "13800002222"},
}

# 保存到文件（dump）
with open("contacts.json", "w", encoding="utf-8") as f:
    json.dump(contacts, f, ensure_ascii=False, indent=2)
    # ensure_ascii=False → 显示中文
    # indent=2 → 格式化缩进

# 从文件读取（load）
with open("contacts.json", "r", encoding="utf-8") as f:
    data = json.load(f)
    print(data["Alice"]["phone"])  # 13800001111
```

**JSON 四兄弟：**
| 函数 | 方向 | 用途 |
|------|------|------|
| `json.dump(obj, file)` | Python → 文件 | 保存数据 |
| `json.load(file)` | 文件 → Python | 读取数据 |
| `json.dumps(obj)` | Python → 字符串 | 序列化 |
| `json.loads(string)` | 字符串 → Python | 反序列化 |

**记忆口诀：** 有 s 是字符串，没 s 是文件。

### ❌ 第33题：文件读写+计算

**原题：** 创建文件写入数字，读取后求和

**正确写法：**
```python
# 第一步：写入数字
with open("numbers.txt", "w", encoding="utf-8") as f:
    for i in range(1, 11):
        f.write(f"{i}\n")

# 第二步：读取并求和
total = 0
with open("numbers.txt", "r", encoding="utf-8") as f:
    for line in f:
        num = int(line.strip())  # 去掉换行符，转成整数
        total += num

print(f"总和：{total}")  # 55
```

**关键点：**
1. 读取的是字符串，要 `int()` 转换
2. 用 `strip()` 去掉换行符
3. 逐行读取省内存

### ❌ 第34题：综合应用

**原题：** 记账本程序

**正确写法：**
```python
import json

# 数据
records = [
    {"item": "午餐", "price": 35},
    {"item": "咖啡", "price": 28},
    {"item": "地铁", "price": 5},
]

# 保存
with open("ledger.json", "w", encoding="utf-8") as f:
    json.dump(records, f, ensure_ascii=False, indent=2)

# 读取并格式化输出
with open("ledger.json", "r", encoding="utf-8") as f:
    data = json.load(f)

print("今日消费：")
total = 0
for r in data:
    print(f"  {r['item']:<6} ¥{r['price']:>6.2f}")
    total += r["price"]

print(f"{'─' * 18}")
print(f"  {'总计':<6} ¥{total:>6.2f}")
```

**输出：**
```
今日消费：
  午餐     ¥ 35.00
  咖啡     ¥ 28.00
  地铁     ¥  5.00
──────────────────
  总计     ¥ 68.00
```
