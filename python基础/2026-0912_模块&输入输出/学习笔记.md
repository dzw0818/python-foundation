# 第一部分：模块

## 一句话理解

**模块 = 一个 `.py` 文件**，里面装着函数、变量、类，可以被其他程序复用。

---

## 1. 导入模块的 4 种方式

```python
# 方式1：导入整个模块
import math
math.sqrt(16)  # 4.0

# 方式2：导入特定函数
from math import sqrt
sqrt(16)  # 4.0

# 方式3：给模块起别名
import numpy as np
np.array([1, 2, 3])

# 方式4：导入所有（不推荐，容易命名冲突）
from math import *
```

| 方式 | 优点 | 缺点 |
|------|------|------|
| `import math` | 来源清晰 | 每次要写 `math.xxx` |
| `from math import sqrt` | 直接用 `sqrt` | 不知道来自哪个模块 |
| `import math as m` | 简短 | 可读性稍差 |
| `from math import *` | 最简短 | ❌ 容易覆盖同名函数 |

## 2. `__name__ == "__main__"` 是啥？

```python
# mymodule.py
def hello():
    print("Hello!")

# 这行代码的意思是：
# 如果这个文件是被直接运行的，就执行下面的代码
# 如果是被 import 的，就不执行
if __name__ == "__main__":
    hello()
    print("这是直接运行时的测试代码")
```

**简单说：**
- 直接运行 `python mymodule.py` → `__name__` 是 `"__main__"` → 执行测试代码
- 被 import → `__name__` 是 `"mymodule"` → 不执行测试代码

## 3. 包（Package）

**包 = 一个文件夹**，里面有多个模块 + 一个 `__init__.py` 文件

```
sound/                    ← 包
    __init__.py           ← 必须有这个文件

```


# 第二部分：输入与输出

## 1. 字符串格式化（3种方式）

### 方式1：f-string（推荐 ⭐）

```python
name = "Alice"
age = 25

# 最简单直接
print(f"我叫{name}，今年{age}岁")

# 可以写表达式
print(f"明年我{age + 1}岁")

# 格式化数字
pi = 3.14159
print(f"圆周率：{pi:.2f}")  # 3.14（保留2位小数）

# 对齐 字符串默认是左对齐，整数是右对齐
for name, phone in [("Alice", 1234), ("Bob", 678)]:
    print(f"{name:10} | {phone:5}")
# Alice      |  1234
# Bob        |   678

# 调试神器：用 = 显示表达式和值
x = 10
print(f"{x=}")  # x=10
```

### 方式2：`format()` 方法

```python
# 位置参数
print("{}和{}".format("苹果", "香蕉"))
print("{1}和{0}".format("苹果", "香蕉"))  # 可以调换顺序

# 关键字参数
print("{name}今年{age}岁".format(name="Alice", age=25))

# 数字格式化
print("{:.2f}".format(3.14159))  # 3.14
print("{:0>5d}".format(42))      # 00042（补零到5位）
```

### 方式3：`%` 格式化（旧式，了解即可）

```python
print("圆周率：%.2f" % 3.14159)  # 3.14
print("%s今年%d岁" % ("Alice", 25))
```

### 对比总结

| 方式 | 推荐度 | 适用场景 |
|------|--------|---------|
| f-string | ⭐⭐⭐ | Python 3.6+，首选 |
| format() | ⭐⭐ | 兼容旧版本，复杂格式化 |
| % | ⭐ | 老代码维护 |

## 2. 文件读写

### 基本操作

```python
# 写文件
f = open("test.txt", "w", encoding="utf-8")
f.write("Hello, World!\n")
f.write("第二行\n")
f.close()  # 别忘了关闭！

# 读文件
f = open("test.txt", "r", encoding="utf-8")
content = f.read()      # 读全部内容
print(content)
f.close()
```

### 推荐写法：用 `with`（自动关闭）

```python
# 写文件
with open("test.txt", "w", encoding="utf-8") as f:
    f.write("Hello!\n")
    f.write("World!\n")
# 离开 with 块，文件自动关闭

# 读文件
with open("test.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)
```

### 文件模式速查

| 模式 | 含义 | 说明 |
|------|------|------|
| `"r"` | 读取 | 默认值，文件不存在报错 |
| `"w"` | 写入 | 文件不存在创建，存在覆盖 |
| `"a"` | 追加 | 写入末尾 |
| `"r+"` | 读写 | |
| `"rb"` | 二进制读 | 图片、视频等 |
| `"wb"` | 二进制写 | |

### 读取方式

```python
with open("test.txt", "r", encoding="utf-8") as f:
    # 方式1：读全部
    content = f.read()
    
    # 方式2：读一行
    line = f.readline()
    
    # 方式3：读所有行（返回列表）
    lines = f.readlines()
    
    # 方式4：逐行遍历（推荐，省内存）
    for line in f:
        print(line, end="")
```

### 写入

```python
with open("test.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")
    
    # 写非字符串要先转换
    num = 42
    f.write(str(num) + "\n")
    
    # 或者用 f-string
    f.write(f"数字是{num}\n")
```

## 3. JSON（保存复杂数据）

列表、字典想保存到文件？用 JSON！

```python
import json

# Python 数据
data = {
    "name": "Alice",
    "age": 25,
    "hobbies": ["reading", "swimming"]
}

# 保存到文件
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f)

# 从文件读取
with open("data.json", "r", encoding="utf-8") as f:
    loaded_data = json.load(f)
    print(loaded_data)

# 转成字符串（不写文件）
json_str = json.dumps(data)
print(json_str)

# 从字符串解析
parsed = json.loads(json_str)
```

| 函数 | 作用 |
|------|------|
| `json.dump(obj, file)` | Python 对象 → 文件 |
| `json.load(file)` | 文件 → Python 对象 |
| `json.dumps(obj)` | Python 对象 → 字符串 |
| `json.loads(string)` | 字符串 → Python 对象 |

## 4. 其他格式化方法

```python
# 右对齐，补空格
"hello".rjust(10)     # '     hello'

# 左对齐
"hello".ljust(10)     # 'hello     '

# 居中
"hello".center(10)    # '  hello    '

# 补零
"42".zfill(5)         # '00042'
"-42".zfill(5)        # '-0042'
```

# 速查表

```
模块导入:
  import xxx                    → 导入模块
  from xxx import yyy           → 导入特定函数
  import xxx as alias           → 起别名
  from xxx import *             → 导入所有（不推荐）

文件操作:
  open(file, mode, encoding)    → 打开文件
  f.read()                      → 读全部
  f.readline()                  → 读一行
  f.readlines()                 → 读所有行（列表）
  f.write(text)                 → 写入
  f.close()                     → 关闭（用 with 就不用手动关）

JSON:
  json.dump(obj, file)          → 写入文件
  json.load(file)               → 从文件读取
  json.dumps(obj)               → 转字符串
  json.loads(string)            → 从字符串解析

格式化:
  f"{var}"                      → f-string（推荐）
  "{}".format(var)              → format()
  "%s" % var                    → 旧式（不推荐）
```
