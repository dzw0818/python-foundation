## 一句话理解

**类 = 模板**（定义一类事物有什么属性和行为）  
**对象 = 实例**（根据模板造出来的具体东西）

```
类：狗（有名字、有品种、会叫）
对象：旺财（名字=旺财，品种=柴犬）
对象：来福（名字=来福，品种=金毛）
```

## 1. 作用域和命名空间

### 四种作用域（从内到外）

```
局部 → 外层函数 → 全局 → 内置
```

| 作用域 | 说明 | 例子 |
|--------|------|------|
| 局部 | 函数内部 | 函数里的变量 |
| 外层 | 嵌套函数的外层 | 闭包 |
| 全局 | 模块级别 | 模块顶层的变量 |
| 内置 | Python 自带 | `print`, `len`, `int` |

### global 和 nonlocal

```python
x = "全局"

def outer():
    x = "外层"
    
    def inner_local():
        x = "局部"  # 新建局部变量
    
    def inner_nonlocal():
        nonlocal x   # 引用外层的 x
        x = "被nonlocal修改"
    
    def inner_global():
        global x     # 引用全局的 x
        x = "被global修改"
    
    inner_local()
    print(f"local后: {x}")       # 外层（没变）
    
    inner_nonlocal()
    print(f"nonlocal后: {x}")    # 被nonlocal修改
    
    inner_global()
    print(f"global后: {x}")      # 外层（没变）

outer()
print(f"全局: {x}")              # 被global修改
```

**口诀：**
- `global` → 改全局变量
- `nonlocal` → 改外层函数变量
- 都不用 → 新建局部变量

## 2. 类的基础

### 定义类

```python
class Dog:
    # 类变量（所有实例共享）
    species = "犬科"
    
    # 初始化方法
    def __init__(self, name, age):
        self.name = name    # 实例变量
        self.age = age
    
    # 方法
    def bark(self):
        return f"{self.name}在汪汪叫"
    
    def info(self):
        return f"{self.name}，{self.age}岁"
```

### 创建对象

```python
dog1 = Dog("旺财", 3)
dog2 = Dog("来福", 5)

print(dog1.name)      # 旺财
print(dog1.bark())    # 旺财在汪汪叫
print(dog2.info())    # 来福，5岁
```

### self 是什么？

`self` 就是对象自己。调用方法时 Python 自动传入。

```python
# 这两种写法等价：
dog1.bark()       # Python 自动传入 dog1
Dog.bark(dog1)    # 手动传入
```

## 3. 类变量 vs 实例变量

| | 类变量 | 实例变量 |
|---|---|---|
| 定义位置 | 类内部，方法外面 | `__init__` 里，`self.xxx` |
| 共享性 | 所有实例共享 | 每个实例独有 |
| 访问方式 | `类名.xxx` 或 `实例.xxx` | `实例.xxx` |
| 适用场景 | 所有对象都一样的属性 | 每个对象不同的属性 |

```python
class Dog:
    species = "犬科"          # 类变量
    
    def __init__(self, name):
        self.name = name      # 实例变量

d1 = Dog("旺财")
d2 = Dog("来福")

print(d1.species)  # 犬科（共享）
print(d2.species)  # 犬科（共享）
print(d1.name)     # 旺财（独有）
print(d2.name)     # 来福（独有）
```

### ⚠️ 类变量的坑

```python
# ❌ 错误：用类变量存可变对象
class Dog:
    tricks = []  # 所有实例共享同一个列表！
    
    def add_trick(self, trick):
        self.tricks.append(trick)

d1 = Dog("旺财")
d2 = Dog("来福")
d1.add_trick("翻滚")
d2.add_trick("握手")
print(d1.tricks)  # ['翻滚', '握手'] ← 被污染了！

# ✅ 正确：用实例变量
class Dog:
    def __init__(self, name):
        self.tricks = []  # 每个实例独立的列表
    
    def add_trick(self, trick):
        self.tricks.append(trick)
        
        
        
d1.tricks = [1] 不会修改类变量。

d1.tricks.append(...)：读到类变量那个共享列表，修改它的内容 → 影响所有实例

d1.tricks = [1]：赋值给 d1，新建实例属性 → 类变量和 d2 都不变

区分点：是"改内容"还是"赋新值"
```

## 4. 继承

### 基本继承

```python
class Animal:
    def __init__(self, name):
        self.name = name
    
    def speak(self):
        return "..."

class Dog(Animal):
    def speak(self):          # 重写父类方法
        return f"{self.name}：汪汪！"

class Cat(Animal):
    def speak(self):
        return f"{self.name}：喵喵！"

dog = Dog("旺财")
cat = Cat("咪咪")
print(dog.speak())  # 旺财：汪汪！
print(cat.speak())  # 咪咪：喵喵！
```

### 调用父类方法

```python
class Animal:
    def __init__(self, name):
        self.name = name
    
    def info(self):
        return f"动物：{self.name}"

class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)  # 调用父类 __init__
        self.breed = breed
    
    def info(self):
        parent_info = super().info()  # 调用父类方法
        return f"{parent_info}，品种：{self.breed}"

dog = Dog("旺财", "柴犬")
print(dog.info())  # 动物：旺财，品种：柴犬
```

### 多重继承

```python
class A:
    def method(self):
        return "A"

class B:
    def method(self):
        return "B"

class C(A, B):  # 继承 A 和 B
    pass

c = C()
print(c.method())  # A（先找左边的）
```

### 类型检查

```python
# isinstance：对象是否是某类的实例
dog = Dog("旺财")
isinstance(dog, Dog)       # True
isinstance(dog, Animal)    # True（继承关系）
isinstance(dog, str)       # False

# issubclass：类是否是另一个类的子类
issubclass(Dog, Animal)    # True
issubclass(Dog, str)       # False
```

## 5. 私有变量

Python 没有真正的私有，靠**命名约定**：

| 命名 | 含义 | 说明 |
|------|------|------|
| `name` | 公开 | 随便访问 |
| `_name` | 受保护 | 约定：别从外部访问 |
| `__name` | 名称改写 | 被改成 `_ClassName__name` |

```python
class Secret:
    def __init__(self):
        self.public = "公开"
        self._protected = "受保护（约定）"
        self.__private = "私有（改写）"

s = Secret()
print(s.public)       # 公开
print(s._protected)   # 受保护（约定）（能访问，但不推荐）
print(s.__private)    # ❌ AttributeError
print(s._Secret__private)  # 私有（改写）（能访问）
```

## 6. 迭代器

让对象可以用 `for` 循环遍历。

### 实现迭代器

```python
class Countdown:
    """倒计时迭代器"""
    def __init__(self, start):
        self.current = start
    
    def __iter__(self):
        return self
    
    def __next__(self):
        if self.current <= 0:
            raise StopIteration
        self.current -= 1
        return self.current + 1

# 使用
for num in Countdown(5):
    print(num)  # 5, 4, 3, 2, 1
```

### 迭代器协议

| 方法 | 作用 |
|------|------|
| `__iter__()` | 返回迭代器对象本身 |
| `__next__()` | 返回下一个值，没有时抛 `StopIteration` |

```python
# for 循环的本质
it = iter(对象)      # 调用 __iter__()
while True:
    try:
        value = next(it)  # 调用 __next__()
        # 执行循环体
    except StopIteration:
        break             # 循环结束
```

## 7. 生成器

用函数写迭代器，更简单！用 `yield` 代替 `return`。

### 基本用法

```python
def countdown(n):
    while n > 0:
        yield n
        n -= 1

for num in countdown(5):
    print(num)  # 5, 4, 3, 2, 1
```

### yield vs return

| | return | yield |
|---|---|---|
| 函数类型 | 普通函数 | 生成器函数 |
| 执行 | 执行完返回，状态丢失 | 暂停，下次从暂停处继续 |
| 返回值 | 一个值 | 多个值（逐个产出） |

### 生成器的好处

```python
# ❌ 列表：一次性生成所有数据，占内存
squares = [x**2 for x in range(1000000)]

# ✅ 生成器：按需生成，省内存
squares = (x**2 for x in range(1000000))
```

## 8. 生成器表达式

用圆括号代替方括号，就是生成器表达式。

```python
# 列表推导式 → 立即生成列表
[x**2 for x in range(5)]      # [0, 1, 4, 9, 16]

# 生成器表达式 → 按需生成
(x**2 for x in range(5))      # <generator object>
```

### 常见用法

```python
# 求和
sum(x**2 for x in range(10))  # 285

# 点积
sum(x*y for x, y in zip([1,2,3], [4,5,6]))  # 32

# 去重
set(word for line in text for word in line.split())

# 找最大值
max(student.gpa for student in graduates)
```

## 7-8. 迭代器和生成器的关系

```
迭代器（Iterator）
├── 手写迭代器类（定义 __iter__ 和 __next__）
└── 生成器（Generator）          ← 更简单的一种
    ├── 生成器函数（用 yield）
    └── 生成器表达式（(x for x in ...)）
```



## 9. dataclass（快捷定义数据类）

```python
from dataclasses import dataclass

@dataclass
class Employee:
    name: str
    dept: str
    salary: int

# 自动生成 __init__、__repr__、__eq__ 等
john = Employee("john", "IT", 10000)
print(john.name)    # john
print(john.salary)  # 10000
print(john)         # Employee(name='john', dept='IT', salary=10000)
```

## 速查表

```
类定义:
  class ClassName:              → 定义类
  def __init__(self, ...):      → 初始化方法
  self.xxx = xxx                → 实例变量

继承:
  class Child(Parent):          → 单继承
  class Child(A, B, C):         → 多重继承
  super().__init__()            → 调用父类初始化
  super().method()              → 调用父类方法

类型检查:
  isinstance(obj, Class)        → 对象是否是该类实例
  issubclass(Sub, Base)         → 是否子类关系

迭代器:
  def __iter__(self):           → 返回迭代器
  def __next__(self):           → 返回下一个值
  raise StopIteration           → 迭代结束

生成器:
  yield value                   → 产出值并暂停
  (expr for x in iterable)      → 生成器表达式

私有约定:
  _name                         → 受保护（约定）
  __name                        → 名称改写
```
